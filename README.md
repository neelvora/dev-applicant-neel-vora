# dev-applicant-neel-vora

A one page marketing site for a fictional credit card called Cardo, from February 2022. Nav across the top, the headline "All the experience in the new credit card" with an order button, a row of stat graphics, and a card face assembled out of individual images. Below that, a grid of six feature cards whose titles, body text, and links are pulled at runtime from a mocki.io mock endpoint.

Only the compiled output is here. `main` holds this README and nothing else, and the Create React App production build lives on the `gh-pages` branch, so there is no source in the repo to read.

The layout is desktop only. Everything is sized in `vmax` and the stylesheet has no media queries at all.
